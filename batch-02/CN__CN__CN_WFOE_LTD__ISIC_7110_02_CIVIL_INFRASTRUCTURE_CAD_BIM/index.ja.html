Paid-up Capital & Blocked Account Regime 払込保管口座の凍結不要

デジタルエンジニアリングおよび設計サービスを提供する完全外資企業（WFOE）の有限責任会社には、法定の最低出資資本は適用されません。登録資本は株主によって決定され、定款に記載されなければなりません。会社法第47条によれば、認購資本は設立から5年以内に全額支払われる必要がありますが、適用される規制制度によってより短い期間が要求される場合もあります。ブロックされたエスクロー口座は必要ありません。資本出資は、海外投資と外国為替登録が完了した後、SAFEが指定する商業銀行に開設された会社の人民元または外貨資本口座に直接送金されます。

Cross-Border Clearing Corridors & Settlement Fit

海外株主は、中国への直接投資株式に対するSAFE BOP取引/投資宣言カテゴリーに基づく、対応する銀行指示を用いて、米ドル、ユーロ、または香港ドルで資本注入を送金する必要があります。通常、銀行システムではFDI株式投資として記録されます（例えば、設立や株式の増加についてはSAFE申告コード621011が使用されます）。送金は、選定された銀行の外資企業専用の外国為替資本口座に振り込まれる必要があります。譲渡前に、WFOEはSAFE FDIの登録を完了し、銀行が承認した外貨登録記録を取得する必要があります。受領後、銀行は資本勘定を入金し、流入額をSAFEに報告し、資本勘定の支払い確認書を発行します。給与、賃貸費、税金、および集団運営費用の人民元への換算には、領収書や契約書が必要です。WFOEは、銀行や定款が要求する場合には、認可を受けた中国の会計士による資本検証報告書も提出しなければならない。いずれの場合も、銀行のFDIデータと確認記録が主な遵守証明となる。

E-commerce / gateway settlement fit: 主要な国内清算システムとしての機能は低い。Wiseや同様のフィンテックEMIは、中国人民銀行や中国銀行保険監督管理委員会によって預金受け入れ銀行や企業口座プロバイダーとして認可されていない。中国に登録された外資系企業は、SAFEの報告要件に従って、外国通貨収入を認可された国内銀行を通じて処理しなければならない。Wiseは、中国法人の運営口座としてではなく、海外親会社の海外財務システムにおいてのみ使用可能である。Wiseは、本土在住の商業法人に対して現地人民元決済口座を提供することを法的に禁止されており、China Settlement Trailを隠すためにWiseを利用しようとする試みは、支払い機関の規制やマネーロンダリング防止の要求に違反することになる。この法人にとって、適切な方法は、正しいサービス・トレード目的コードを持つ国内銀行のキャッシュアカウントへのSWIFTワイヤー送金であり、EMIの支払いシステムではない。

Strike-off trigger

Mandatory Audit Threshold 小規模企業の監査免除制度

Turnover: 中国の外資系独資会社には、最小限の定量免除規定は適用されません。年次監査は、当該企業が中国の外資系有限責任会社であるため、必須です。中国会社法および外資投資報告制度に基づき、資産負債総額、売上高、従業員数、または外資系独資会社が活動していないかどうかにかかわらず、中国認可の会計士を任命する義務があります。したがって、定量トリガー基準は免除として適用されません。さらに、外資系独資会社が後に中国証券監督管理委員会/中国銀行業監督管理委員会/国家互動情報センターの規則に基づき上場会社、金融機関、公益団体に指定された場合も、より厳格な監査や公的発行の要件が適用されます。

Box-by-Box Return Breakdown (non-resident focus)

BoxField Non-resident guidanceTax-evasion pitfall
ボックス1 / 行1 - 売上収入（英葉収入） 民間インフラのCAD/BIM設計、離島のビルディング情報モデリングサービス、ソフトウェアライセンスおよび関連するエンジニアリングアウトソーシング契約から得られる総収入。 WFOEは主に中国大陸における居住者としての課税対象となり、世界中の収入をこの項目に含める必要があります。WFOE自体は非居住企業ではありません。中国において海外顧客向けに実施されるクロスボーダーCAD/BIM業務に関しては、実際に適用された完了契約法または入力課税法に基づいて収入を認識しなければなりません。関連会社へのサービス料金の再収入については、公正な価格でなければならず、書面による契約に基づき、移転価格ドキュメントと整合性を保たなければなりません。外国の関連会社とのサービス収入（または支出）を記録しないことは、審査において典型的な赤旗となります。
ボックス2 / 行2 - 経営費用（英業成本） BIM/CADサービス提供にかかる直接的な費用、包括的にBIMエンジニアの給与、クラウドサブスクリプション料、ソフトウェアの償却費、図面作成の請負コスト、レンダリング用ハードウェアの償却費および直接的なプロジェクト運営費。 実際に中国で提供されるサービスに関連する費用のみが控除可能です。BIMワークフローの一部が外国の関連企業や共同サービスセンターに委託されている場合、WFOEは公正な対価の証拠を同時に取得し、その外国の下請け業者がCAD/BIMの使用料や技術サービス料に関して中国の関税義務を遵守していることを確認しなければなりません。外国本社の費用の「仮定上の」分担についての控除は、有効な費用分担契約が存在しない限り拒否されるべきです。
ボックス3 / 行3 - 税金および追加料金（税金および追加料金） 税年中に支払われた控除可能な事業税および手数料。これには、都市維持・建設税、教育手数料、印紙税、および消費税関連の地方手数料が含まれる。 WFOEは、この項目をVAT申告書および銀行支払記録と照合する必要があります。非居住者供給業者については、WFOEが源泉徴収担当者として、ロイヤルティや利息の支払い時にVATおよび法人所得税を源泉徴収しなければなりません。適切な提出期間内に源泉徴収を報告しない場合、対応する控除が無効となり、利息や罰金が発生します。
ボックス4 / 行4 - 売上費用（小売費用） 広告費、入札費用、国際展示費用、海外顧客への出張費、販売代理店またはビジネス開発パートナーへの手数料。 中国のPE（中国の経済的権益を持つ法人）を持たない非居住地の販売代理店に対して報酬が支払われた場合、WFOE（中国における外資系法人）は、その支払いを非居住地のサービス料として扱い、そのサービスが中国で提供されたと見なされた場合に、控除申告義務を履行しなければならない。税務的に有利な管轄地域に設立された、実際の事務所や従業員、リスク負担機能を備えていない「メールボックス会社」形式の販売代理店は、利益所有者テストを満たさず、再分類され、控除が認められない可能性があり、付加価値税（WHT）が発生する可能性がある。
ボックス5 / 行5 - 管理費 中国のWFOEの事務所賃料、地方行政の給料、専門家手数料、取締役手数料、保険料および一般的な会社経費。 この項目は、経済的な実態を示す主要な証拠です。CAD/BIMサービスを提供する外国法人については、税務当局は中国に現地の事務所施設、フルタイムの設計エンジニア、プロジェクトマネージャー、意思決定者、会計スタッフが存在することを期待します。実際のサービスがないにもかかわらず、外国親会社が課す過度な管理費用は控除できず、隠れた利益の送金として調整される可能性があります。親会社の料金は、契約、時間配分、成果物、そして有益な所有権といったものによって裏付けられている必要があります。
ボックス6 / 行6 - 金融費（財務費） 銀行ローンおよび子会社間の借入に対する利息費用、銀行手数料、保証手数料、および純外貨為替損失。 非居住者向けの貸し手や外国株主に対して支払われる利息は、薄資本化規制の対象となります。控除可能な利息は、一般的に非金融企業には2:1の負債対資本の安全保護比率に限られます（金融企業では4:1）。WFOEは、税務協定で税率が減額されない限り、海外からの利息に対して10％の企業所得税を控除しなければなりません。減額された税率を適用する前には、税籍証明書と実質所有権証明書を取得する必要があります。外国為替損失は実現し、記録する必要があります。未実現の外国為替損失は戻すことができます。
ボックス7 / 行7 - 資産減損損失（資産減損損失） 不良債権の備品、契約資産の減価、収入の損失備品、および不活性な設備またはソフトウェアの減価処理。 税法では、実際の損失に対する控除のみが認められており、一般的な不良債権に関する規定はCITにおいて控除できない。会計上の減損と課税可能な廃止との違いは、税務調整表に記載する必要がある。受取金が海外の関連企業から来ている場合、独立系外国法人は実際の消滅と商業的目的を証明しなければならない。放棄された関連企業の受取金は、隠れた利益の送金の兆候であり、配当付加税および罰金を招く可能性がある。
ボックス8 / 行15 - 総利益（リーチン ゾン エ） 中国の会計基準または認められた財務報告枠組みに基づいて算定された、税務申告における調整前の会計前利益。 WFOEの場合、総利益は審査された財務諸表と一致しなければならない。WFOEは、関係者取引の申告書に、非居住者株主からの貸借、賃貸、特許料、サービス、配当金の支払いをすべて明示しなければならない。利益を低税率地域に移転させたり、収益を海外に記録しつつ、費用や従業員を中国に残すことで人工的に低くした総利益は、移転価格調整、利息、ペナルティ、さらには代表者に刑事責任が生じる可能性がある。
