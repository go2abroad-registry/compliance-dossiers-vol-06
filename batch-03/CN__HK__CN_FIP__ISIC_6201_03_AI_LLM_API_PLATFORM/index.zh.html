外汇管制自由度 中国维持经常项目可兑换制度：真实贸易和服务支付可在经授权银行核实后办理结算，但资本项目交易需经国家外汇管理局（SAFE）登记、额度控制或特定审批。外商投资合伙企业（FIP）可接受香港合伙人以外币形式的资本投入，但资金须通过SAFE登记的资本项目账户汇入，并且只有在银行核实了相应的外商直接投资（FDI）记录后，方可将外币兑换为人民币。人民币兑换并非无条件：结汇所得款项必须用于FIP经批准的经营范围，不得流入禁止领域，如无牌照的证券投资或投机性房地产，亦不得以违反SAFE相关通知的方式用于偿还境内人民币贷款。利润汇出至非居民合伙人，通常需在年度审计、税务清缴以及经审计的会计师事务所出具的可分配利润证明文件后方可进行，但合伙制下的穿透税制可能对归属于非居民合伙人的中国来源收入产生预提税义务。香港司法管辖区完全可兑换，港元对美元汇率稳定在7

法定注册代理人与物理地址 强制持牌代理

对于香港，有限合伙企业的注册办事处必须是位于香港的实体地址，能够接收法律文书。如果该地址为真实存在的、有工作人员的实体地址，并且服务提供商承诺接收并转交文件，则可接受虚拟办公室或商业信箱。然而，税务局（IRD）及银行可能将低实质性的虚拟办公室视为高风险；对于采用加密货币支付通道的AI大语言模型（LLM）API平台，独立银行可能要求提供租赁协议或服务式办公室协议、公司信头以及普通合伙人必须具备实体存在。虚拟办公室并非被法律明文禁止，但纯邮政信箱地址很可能被拒绝。

没有。根据中国合伙法，外资合作企业没有法定的最低注册资本要求，也没有最低实收资本要求，也不存在冻结托管账户的要求。合伙人可以在合伙协议中确定出资额、形式及安排；出资可以是现金、实物资产、知识产权或技术。从香港汇出的任何外币出资必须通过银行业务进行，并符合国家外汇管理局的规定进行外汇登记，但这属于外汇合规要求，并非对资本的限制。

第一届董事会及合伙人会议决议书：[名称] 外商投资合伙企业。于[日期]在[时间]于注册地址召开的董事会及管理合伙人委员会及上述外商投资合伙企业的合伙人会议，经合法召集并召开，一致通过以下决议：

2. 资本认缴：决议确认各合伙人按资本结构表所列的出资额予以认缴；鉴于现行法律法规未设定最低实缴资本及资金托管锁定期，各合伙人应根据约定时间以现金、实物资产、知识产权或技术等形式进行出资；执行合伙人应签发出资证明书，并建立资本台账。

4. 法定职务：决议任命[姓名]为执行合伙人，[姓名]为授权代表及税务合规官，[姓名]为反洗钱合规官；执行合伙人享有全面管理权，有权开设银行账户、签署合同，并在监管及商业交易对方面前代表本外商投资合伙企业；授权代表有权签署年度申报文件及税务申报材料。

外汇管制与央行政策诊断

经常项目兑换自由度

中国维持经常项目可兑换制度：真实贸易和服务支付可在经授权银行核实后办理结算，但资本项目交易需经国家外汇管理局（SAFE）登记、额度控制或特定审批。外商投资合伙企业（FIP）可接受香港合伙人以外币形式的资本投入，但资金须通过SAFE登记的资本项目账户汇入，并且只有在银行核实了相应的外商直接投资（FDI）记录后，方可将外币兑换为人民币。人民币兑换并非无条件：结汇所得款项必须用于FIP经批准的经营范围，不得流入禁止领域，如无牌照的证券投资或投机性房地产，亦不得以违反SAFE相关通知的方式用于偿还境内人民币贷款。利润汇出至非居民合伙人，通常需在年度审计、税务清缴以及经审计的会计师事务所出具的可分配利润证明文件后方可进行，但合伙制下的穿透税制可能对归属于非居民合伙人的中国来源收入产生预提税义务。香港司法管辖区完全可兑换，港元对美元汇率稳定在7.75至7.85之间，股息、贸易收入及资本返还均无需交割或审批。因此，实际操作中的摩擦主要集中在内地资本项目，而非香港的可兑换性，任何跨境资金流动均需严格匹配相关文件。

出口外汇强制结汇要求

根据2012年中国外汇改革政策，出口收入强制兑换比例实际上为零；出口商无需将外币兑换成人民币。不过，所有海外出口或服务收入都必须返回到中国内地，而商品出口收入的法定基准期限通常为海关申报日期起180天。服务贸易收入，包括人工智能和软件API费用，可以在外汇结算账户中保留，或按银行即期汇率进行兑换，前提是相关合同、发票和税务证明能够提供。超过指定账户限额的剩余外币必须通过银行外汇监控系统向国家安全部报告，而任何兑换成人民币的行为都是自愿的。香港对出口收入没有强制上缴规定。

央行监管: 外汇管理局（SAFE），由中国人民银行（PBOC）授权；针对香港部分，香港金融管理局（HKMA）实施联系汇率制度，不存在外汇管制。

香港合作伙伴应从其持牌香港银行账户，通过SWIFT MT103方式，或对于较大额度的港元转账，通过HKD CHATS结算指令，将资金转入中国银联、建设银行或招商银行的SAFE注册资本项目外汇账户。汇款时必须注明FIP为受益人，注册后的香港合作伙伴为汇款人，且需使用银行批准的SAFE直接投资资本投入用途代码，通常称为SAFE交易代码601，用于直接投资的股权或合伙资本。银行在入账前会要求提供SAFE直接投资注册凭证、FIP的合伙证书、资本投入清单以及内部指示函件。收到上述文件后，银行会通过SAFE直接投资报告系统进行资本验证，由持牌注册会计师出具或更新资本验证报告。只有在银行提交了“资本项目结算”记录，并确认资金被用于FIP所批准的AI/LLM API业务操作后，才允许从资本项目账户进行人民币结算。来自海外客户的重复使用的AI API订阅费用，应通过SWIFT MT103方式汇回国内，并附上正确的服务贸易目的代码、商业发票以及完整的SAFE当前账户验证声明。对于大型定制AI模型部署合同，如果合同中有可衡量的交付/验收节点以及可验证的软件出口文件，则可以使用商业信用证。包括D/P和D/A在内的单据结算方式，适用于维护续费、模型版本发布以及基于节点的许可分期支付等场景，此时交易方需要运输凭证。FIP必须通过直接成员银行进行境内外币结算，不得通过大陆银行系统直接传输USDC或其他加密货币。香港财政节点可以通过持牌香港VASP将USDC转换为HKD/USD，然后通过CHATS/SWIFT传输给大陆银行进行境内转换。境内允许交易以真实贸易或资本敞口为标的的人民币/美元远期合约，期限通常不超过12个月，对冲比例不得超过承诺收款或付款的100%。离岸人民币非交割远期（CNH/USD NDF）仅限于香港财政节点使用，不得在内地自贸区使用；境内NDF在大陆中国境内不允许。仅在存在真实债务或跨境融资流动的情况下，方可进行本外币利率互换，例如香港合作伙伴的期限贷款转换为人民币。互换的名义金额必须与基础合同一致，需经董事会批准，并在适用情况下向国家外汇管理局（SAFE）进行备案。

电商与网关结算适配度: 中国FIP的状况为低至条件性低水平。像Stripe、Wise和Revolut Business这样的离岸数字支付平台，在法律上未被授权为中国内地企业开设主结算账户或通过中国人民银行支付系统处理人民币清算。如果相关资金最终存入获得完全许可的香港银行，并通过SWIFT传输到FIP，那么Stripe可以仅作为香港金融中心节点的前端卡支付网关发挥作用。以加密货币USDC作为结算方式的方案对于中国FIP来说不可行；香港节点可以通过获得许可的香港虚拟资产服务供应商将USDC转换为HKD/USD，之后才可以在境内进行法定货币HKD/USD的转账。因此，FIP应将国内一级银行视为必要的核心渠道，而将金融科技支付平台视为辅助性的发票工具，而非受监管的银行渠道。

致命合规红线与董事个人责任

逃税——虚假的穿透分配及预提税未缴

法定制裁: 《TCAL》第63条规定，需补缴欠缴税款，并加收每日0.05%的延迟支付附加费，同时处以相当于逃税金额50%至5倍的罚款；《TCAL》第69条则要求FIP作为预扣代理人，对未收取的预提所得税负责；《中国刑法》第201条规定，逃税金额达到10万元人民币或当年应缴税额的10%时，即构成犯罪。

董事个人责任: 公司普通合伙人董事若明知并指令进行虚假分配，将承担个人责任；根据公司法第20条，揭开公司面纱，暴露个人财产；税务机关将责令返还非法取得的财产；对法定代表人及董事实施出境限制、旅行禁令或列入黑名单；在情节严重的情况下，董事可能被判处最高七年有期徒刑。
空壳公司与税收协定滥用（受益所有权欺诈）

法定制裁: 根据《税收协定》公告[2019]年第35号拒绝享受税收协定待遇，随后按法定税率10%进行最终预扣税评估；香港税务局可撤销公司的居民身份证明书，前提是该公司并非在香港进行管理和控制；同时，若未提供相关信息，将触发内地《税收征管法》第44条规定的处罚，并处以最高不超过人民币5万元的罚款。

董事个人责任: 香港名义公司及大陆有限合伙企业（GP）的董事均可能面临公司人格被穿透的风险；名义董事在虚假受益所有权声明上签字，构成《香港罪行条例》第200章第36条的刑事虚假陈述罪，最高可判处14年监禁；大陆籍董事被列入税务欠款黑名单，将面临旅行禁令和资产冻结，直至补缴未缴的10%预提所得税及相应罚款为止。
转让定价不合规及缺乏经济实质

法定制裁: 《中华人民共和国税收征收管理法》第41条规定了公平交易原则；税务机关可以重新分配利润，并征收相当于利润调整金额的100%加上利息；《税务征收管理条例》第32条规定，在审计年度内未按时缴纳的税款，需按日支付0.05%的滞纳金；《税务征收管理条例》第63条还规定了50%至5倍的民事处罚；故意伪造同期文件的行为可根据刑法被视为税务欺诈行为。

董事个人责任: 批准或签署人为价行为的董事，构成逃税的共犯；根据《公司法》第21条及第20条揭开公司面纱的规定，可能需就公司损失承担赔偿责任；在税务执法阶段，对所有董事、高级管理人员及受益所有人实施旅行禁令和列入黑名单；若被定罪，虚开发票定价行为的量刑为：若逃避税额超过刑事标准，处三年以下有期徒刑；若金额重大，处三年以上七年以下有期徒刑（《中华人民共和国刑法》第201条）。
