Export 0% zero-rating conditions

Für Waren gilt eine Mehrwertsteuer (MwSt.) von 0 % nur dann, wenn die Waren an einen ausländischen Kunden verkauft werden, physisch aus dem Zollgebiet der Volksrepublik China (PRC) exportiert werden und durch eine elektronische Zollexporterklärung, Transportdokumente sowie eine Fremdwährungszurückführung nachgewiesen werden.
